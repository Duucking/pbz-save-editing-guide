# NOTICE

This repository contains documentation and helper scripts for reading and
modifying **Phantom Blade Zero / 影之刃零** (Steam) single-player save files.

- No game executables, game assets, save files, or player data are included.
- The Oodle decompression library (`oodle-data-shared.dll`) is **not** bundled.
  It is a third-party component; obtain it from the OodleUE project releases:
  https://github.com/WorkingRobot/OodleUE/releases
- Oodle is a trademark of Epic Games. Phantom Blade Zero is a trademark of its
  respective owners. This project is unofficial and not affiliated with them.
- The scripts are provided as-is, without warranty. Always back up saves before
  modifying them. Use only on your own single-player saves.

Third-party references:

- PBZ-Editor: https://github.com/qry6868/PBZ-Editor
- PBZERO: https://github.com/idedit/pbzero
- oozextract: https://github.com/lvlvllvlvllvlvl/oozextract
- CUE4Parse / OodleUE: https://github.com/WorkingRobot/OodleUE
- PBZ Save Reader: https://github.com/gudqs7/pbz-auto-splitter
